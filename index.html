⚙️ Settings

Versi awal ini menyimpan data di browser perangkat. Menghapus data browser dapat menghapus karya yang belum diekspor. Ekspor cadangan secara berkala.

Data & privasi

Karya disimpan di localStorage browser pada perangkat ini. Tidak ada akun, sinkronisasi, atau publikasi daring dalam prototipe ini.

Langkah menuju publikasi

  1. Uji file ini di browser Android.
  2. Unggah ke layanan hosting statis untuk memperoleh alamat website.
  3. Tambahkan manifest dan service worker agar lebih layak dipasang sebagai PWA.
  4. Bangun backend untuk akun, sinkronisasi, komunitas, dan integrasi AI yang aman.
